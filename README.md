# bankDatabase

##  Description
A simple banking system built with Python and SQL. It supports user login and basic banking uses like checking balance, depositing, and withdrawing money. 


## How to Run

1. Make sure Python 3 is installed:
```bash
python3 --version
```
2. Run the program:
```bash
python3 main.py
```
